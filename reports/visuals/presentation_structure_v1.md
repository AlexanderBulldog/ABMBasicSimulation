# Каркас выступления: проект + индивидуальный трек

## 1) Единая сводка по работе (в одном месте)

### 1.1 Общий план проекта (рамка)
1. Построение и валидация моделей вероятностного прогнозирования динамики эпидемиологических, экономических, экологических и социальных процессов.
2. Получение и представление результатов валидации таких моделей.

### 1.2 Что уже сделано (по WorkPlan/WorkStatus + ваш индивидуальный план)
- Сформирован воспроизводимый контур калибровки ABM: `ABM -> DOE -> Emulation -> History Matching -> Refinement -> Validation`.
- Зафиксирована формальная постановка history matching для вектора параметров (13 параметров модели), с implausibility-критерием и NROY-областью.
- Выполнены 2 волны дизайна эксперимента (LHS):
  - Wave 1: 400 точек, 3 стохастические реплики, горизонт 180 шагов.
  - Wave 2: 400 точек в суженном пространстве параметров.
- Введена фильтрация нестабильных прогонов (`bad runs`), исключающая вырожденные и некорректные траектории.
- Построены GP-эмуляторы по метрикам:
  - эмулируется примерно 22 из 26 целевых метрик;
  - типичное качество кросс-валидации: `R2 ~ 0.60-0.65`.
- Проведён history matching:
  - порог implausibility: `I < 3`;
  - доля NROY: около `50%` (wave 1) и `48%` (wave 2);
  - медианный `I_max` во 2-й волне около `3.0`.
- Выполнено итеративное сужение интервалов параметров (ориентир `p05-p95`): среднее сокращение ширины интервалов `12-14%`.
- Предварительный анализ чувствительности/неопределённости показал доминирование `model discrepancy (MD)`; вклад `CU` минимален, `EV` вторичен.
- Валидация на репрезентативных точках NROY (6-8 точек, горизонт до 400 шагов, все реплики): без макроколлапсов и банковских сбоев.
- По индивидуальному треку:
  - выполнен обзор литературы по ABM в экономике, mean-field, DL/MARL/суррогатам;
  - выполнена постановка задачи для гетерогенной популяции агентов и выбор тестовых доменов;
  - подготовлены эмпирические/синтетические датасеты и протоколы верификации;
  - выполнен предварительный анализ чувствительности;
  - базовая гетерогенная ABM и mean-field аппроксимации находятся в стадии развития/углубления.

### 1.3 Что делается сейчас
- Усиление дискриминационной способности калибровки: ужесточение допущений по модельной неопределённости и критериев отсечения.
- Сопоставление результатов на альтернативных наборах таргетов/сценариев.
- Доработка связки «гетерогенная ABM <-> mean-field» и проверка численной устойчивости схем.

### 1.4 Что будет сделано дальше
- Третья итерация уточнения NROY (или эквивалентный refinement-проход) с более строгими таргетами.
- Углублённая валидация на расширенном горизонте и стресс-сценариях.
- Формализация сравнений ABM vs mean-field по точности, устойчивости и вычислительной цене.
- Подготовка итогового набора визуальных схем/таблиц для защиты результатов валидации.
