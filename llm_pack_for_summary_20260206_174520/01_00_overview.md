# 0) Executive summary

## Что это

Репозиторий содержит агентную макроэкономическую модель (ABM) на Mesa (**домохозяйства + фирмы + банк**) и пайплайн для:

1) массовых прогонов по пространству параметров (LHS),  
2) построения суррогатной модели (**эмулятора**: GPR, контроль — RF),  
3) отбора области параметров, согласованной с “таргетами” (**history matching / NROY**),  
4) итерации (wave2) в суженном пространстве,  
5) отбора “репрезентативных” траекторий для презентации/отчёта,  
6) построения датасета и ML‑политики фирм (наценка/ценообразование).

## Вход → Модель → Выход (одной строкой)

- **Вход**: набор параметров `theta` + `seed` + `steps`.  
- **Модель**: ABM `EconomyModel` (агенты, рынки, дефолты, банк с bail‑in/bailout).  
- **Выход**: временные ряды агрегатов + сводные метрики (mean по окну, доли/ставки), далее — эмулятор и history matching.

## Зачем делалась стабилизация

В “baseline” версии часть прогонов и даже один из “репрезентативных” сценариев коллапсировали (занятость/выпуск/потребление → 0 на длинном горизонте).  
Для семинара/статьи важнее иметь **стабильный отчётный набор** (report set), чем максимально широкий априорный диапазон.

## Итог (baseline vs seminar)

Ключевой практический результат: в “seminar” отчётный набор `output_seminar/results/report_set_wave2` **не содержит коллапсов**, и для всех 6 точек (seeds 0/1/2) выполнены:

- `Employment_mean`, `Output_mean`, `Consumption_mean` строго положительные,
- `BankFailed_share = 0`,
- `BankBailedOut_share = 0`,
- `BalanceOK_share = 1`.

При этом history matching по таргетам стал существенно “мягче” (меньше `I_max`, выше доля NROY в wave1), но среднее качество эмулятора (CV R²) стало чуть ниже — это ожидаемо из‑за строгой фильтрации “плохих” прогонов в датасете.

## Ограничения (важно проговорить на семинаре)

- В исходном пространстве параметров присутствуют “вырожденные” режимы (коллапсы); в seminar‑версии они отделены в `bad_run` и не используются для эмулятора/HM.
- Даже среди good runs заметна доля режимов с `HH_Deposit_mean==0` (см. `reports/2026-01-25_seminar/03_results.md`), что может требовать донастройки конфигов/таргетов в будущей работе.
